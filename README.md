# SAM-AutoAnnotator-
基于 SAM 2 与深度追踪算法（NanoTrack/DaSiamRPN）的视频/图像序列智能标注工具，支持像素级多边形分割与目标检测框自动追踪标注，兼容 VOC、COCO 及 YOLO 多种数据导出格式。
An intelligent video/image sequence annotation tool powered by SAM 2 and deep tracking engines (NanoTrack/DaSiamRPN). Features automatic polygon segmentation tracking and bounding-box annotation, with exports to VOC, COCO, and YOLO formats.
